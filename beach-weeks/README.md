# beach-weeks

React SPA for the iGoodTimes beach week calendar. See the [root README](../README.md) for full project context.

## Commands

```bash
pnpm dev       # http://localhost:5173
pnpm build     # tsc + vite build
pnpm test      # vitest run
pnpm lint      # oxlint
pnpm generate  # regenerate src/data/beachWeeks.ts
pnpm deploy    # build + deploy to Cloudflare Pages (dev branch)
```
